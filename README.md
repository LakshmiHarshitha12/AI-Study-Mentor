 AI Study Mentor

An AI-powered study assistant that helps users learn from PDF and Word documents.

## Features

- 📄 Upload PDF and Word documents
- 📖 AI-generated summary
- 📜 Topic history
- 🎯 Important topics
- 🧠 Key concepts
- ❓ Interview questions
- 📝 Quiz generation
- 🃏 Flashcards

## Tech Stack

- Python
- Streamlit
- Groq API
- Llama 3.3 70B
- PyMuPDF
- python-docx
